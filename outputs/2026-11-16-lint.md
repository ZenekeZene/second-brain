## FIX INMEDIATO — SessionStart hook (< 1 minuto en el Mac)

Este es el único cambio que rompe el ciclo. 10 semanas sin aplicar.

Editar `.claude/settings.json` en el Mac/Pi:

**Actual:**
```json
"hooks": {
  "SessionStart": [
    {
      "hooks": [
        {
          "type": "command",
          "command": "node bin/status.mjs"
        }
      ]
    }
  ]
}
```

**Debe quedar:**
```json
"hooks": {
  "SessionStart": [
    {
      "hooks": [
        {
          "type": "command",
          "command": "git checkout master 2>/dev/null || true"
        },
        {
          "type": "command",
          "command": "node bin/status.mjs"
        }
      ]
    }
  ]
}
```

Luego:
```bash
git add .claude/settings.json
git commit -m "fix: add git checkout master to SessionStart hook"
git push origin master
```
